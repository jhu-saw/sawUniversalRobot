Change log
==========

1.2.0 (TBD)
===========

* Provides a SAW component for UR3, UR5, UR10, UR16, and UR20 robots through
  the Universal Robots real-time scripting/socket interface.
* Supports CB2, CB3, and e-Series robot controllers, including Dashboard Server
  communication.
* Includes C++ integration and optional ROS 1/ROS 2 support for joint-state and
  3D transformation publishing.
* Build:
  * Raised the minimum CMake version to 3.16.
